# 提示词工坊 · PromptForge
有一定的功能性，但不多
## 功能特性

- 自然语言需求输入，自动解析任务、目标、受众、语气、长度、约束、关键词
- 11 种提示词框架：CRISPE / RTF / BROKE / CO-STAR / RACE / APE / TAG / CLEAR / RISE / SELF / 自定义
- 8 个输出版本：标准版 / 详细版 / 精简版 / 专业版 / 口语化 / 思维链 / 少样本 / 角色扮演
- 六维质量评分（清晰度、具体性、上下文、约束、格式、可执行性）与改进建议
- 内置 13 个常用模板（写作、编程、视频、营销、学习、办公、面试、游戏攻略等），支持搜索、收藏、自定义、导入导出
- 模板变量面板（{{主题}} 等）：填写后实时替换预览
- 历史记录：搜索、置顶、收藏、删除、存为模板
- 导出：一键复制、下载 TXT / Markdown / JSON、生成提示词卡片图片
- 深色模式（浅色 / 深色 / 跟随系统）
- 数据备份与恢复（JSON）
- 可选 AI 增强：OpenAI 兼容接口 / Claude / Gemini / 豆包（需自备 API Key）

## 快速开始

直接双击打开 `提示词工坊.html` 即可使用，无需联网、无需安装。

## 使用说明

1. 在首页或生成页输入你的需求（例如：写一篇关于人工智能的公众号文章，面向产品经理，800 字左右）
2. 点击「生成提示词」，自动完成需求解析、框架选择、结构化生成、质量评分
3. 在结果区切换 8 个版本，一键复制或导出
4. 模板页可使用内置模板，或点击「新建模板」把常用提示词存为自定义模板

## AI 增强（可选）

进入「设置」页填写：

- 服务商：ChatGPT / Claude / Gemini / 豆包
- API Key 与接口地址（OpenAI 兼容格式）
- 模型名称

> API Key 仅保存在本机浏览器 localStorage，只在点击「AI 增强」时发送给对应服务商；不配置也可完整使用全部离线功能。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库并把本文件夹内容推上去（步骤见 `上传说明.md`）
2. 仓库 Settings → Pages → Source 选择 `main` 分支 `/ (root)`
3. 保存后访问 `https://<用户名>.github.io/<仓库名>/提示词工坊.html`

## 技术说明

- 原生 HTML + CSS + JavaScript，无第三方依赖、无构建步骤
- 数据存储：浏览器 localStorage（模板 / 历史 / 设置）
- 隐私：默认全部在本地处理，不上传任何数据
